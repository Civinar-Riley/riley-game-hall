# 合成大西瓜 · 果日小铺验证记录

日期：2026-10-25

## 实现范围

新增大厅第 8 款游戏。HTML、Canvas、原生 JavaScript、Three.js 负责界面与 2.5D 渲染，Matter.js 负责二维圆形物理。构建时将依赖、程序化水果、样式、声音与逻辑内联到 `public/games/suika.html`，不使用运行时外部 CDN。

- 经典模式：最大西瓜保留、不再合成，继续冲分。
- 收集模式：合成西瓜立即消失并累计数量，仍可堆满失败。
- 11 级水果链，前 5 级随机投放；每局移除 2 次、摇一摇 1 次。
- 连续超线 3 秒失败，入场短暂保护，暂停不计时。
- 两模式分别保存局面、道具、当前/下一颗水果、纪录；恢复先暂停。
- 鼠标点击、触屏松手投放、键盘方向键/空格；静音可记忆。
- WebGL 不可用时保留 Canvas 2D 玩法。

## 浏览器验证限制与错误

工具多次出现以下错误，失败调用没有被记录为测试通过：

- `unable to attach frame target ...`：无法使用元素定位附着大厅沙箱 iframe。
- `browser screenshot surface preparation timed out after 3000ms`。
- `browser 命令 screenshot 超时（30000ms）`。
- 部分点击等待超时；后续独立 DOM/截图观察用于判断实际是否发生动作，没有注入脚本触发动作。

重新加载后可以再次观察页面，但超时也发生在独立游戏页，最终未完成完整实玩验证。当前工具未提供控制台日志读取能力，没有收集到控制台错误日志；不代表页面没有控制台错误。
